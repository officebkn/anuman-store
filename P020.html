V6 พัฒนาต่อจาก V5 - ไม่เขียนทับไฟล์ต้นฉบับ
1. รักษาของเดิมจาก v5 - เมนู สี Dashboard ตารางเวร ข้อมูลเดิม (employees, visitors, goods, patrols, incidents, roster, guards, shifts, points) ใช้ได้ต่อเนื่อง
2. ระบบผู้ใช้ 4 ระดับ - รปภ. / หัวหน้า รปภ. / ผู้จัดการ / Admin (สิทธิ์แยกกันชัดเจน)
3. ระบบอนุมัติสิ่งของ - รออนุมัติ → อนุมัติ → ไม่อนุมัติ → ตรวจสอบก่อนนำออก (ต้องมีลายเซ็น + รปภ. ตรวจ)
4. ระบบภาพหลักฐาน - รูปถ่ายแสดงได้ทั้งใบผ่านและรายงาน (แก้บั๊กเหตุฉุกเฉินแล้ว)
5. ระบบลาดตระเวน - QR/Barcode พร้อมบันทึกเวลาและจุดตรวจ + พิมพ์เอกสาร
6. ระบบรายงาน - ค้นหา กรองรายวัน/รายเดือน พิมพ์เอกสาร
7. ระบบสำรองข้อมูล - ส่งออก นำเข้า และสำรองอัตโนมัติก่อนแทนที่
